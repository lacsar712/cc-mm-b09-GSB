# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 可疑粘滞检测

同一测点按时间相邻的两笔，若浓度差绝对值小于检查员设定的粘滞门槛（默认 0.05）：

- **现场可疑页**：按当前门槛实时重算，改大门槛会多出对、改小门槛会消失。
- **可疑册**：只在新笔检出当时写入，冻结检测时的门槛、前后两笔主键、差值与写入时刻。事后无论把门槛改大改小，旧册行的门槛与差值都保持检出时的原文，也不会把历史对补入册。
- 只读账号（viewer）可翻现场页与册页，但不可改门槛；顶栏「可疑册」所有登录用户可进。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。

3. viewer 登录后没有上报表单。
