# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 可疑粘滞检测

同一测点按时间相邻的两笔读数，浓度差绝对值小于检查员设定的粘滞门槛（默认 0.05）时：

- **现场可疑页**：按当前门槛对全部读数实时重算，只展示不落档。改大或改小门槛只影响本页。
- **可疑册**：检出当时即存档冻结，册行保留检出时的门槛、前后两笔主键、前后浓度、差值与写入时刻，之后门槛如何调整都不改变旧册行。
- 顶栏可进入可疑册。gasman 可改门槛；viewer 只能翻看现场页与册页，不能改门槛（接口返回 403）。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. gasman 在东翼-12 连续报 0.35 和 0.36，门槛 0.05 时现场可疑页与可疑册都出现该对（差值 0.01）。把门槛改成 0.005 后现场页该对消失，但可疑册仍保留门槛 0.05、差值 0.01 的那一行；viewer 看不到改门槛的表单。
